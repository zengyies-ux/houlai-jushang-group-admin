## 本地验证命令与结果

- `npm run build`：通过，包含 TypeScript 检查、Vite 与服务端构建。Vite 有超过 500 kB 的资源体积提示，不影响构建。
- `npm test`：6 个测试文件、9 个测试通过，覆盖工作状态与日期规则、团队任务闭环、周/月任务同步、统计视图、备份恢复、旧库升级和图片存储。
- 浏览器人工操作：在隔离数据目录创建小组、成员和任务；把未分组成员分入小组；核对同一任务在周/月视图显示；上传背景和头像，再移除头像，确认默认显示姓名首字。切换深色模式并重新载入，检查成员抽屉、设置页、文字对比度和壁纸遮罩数值。原 V0.1 的完整任务闭环浏览器检查仍保留。测试数据不进入正式数据目录。
- `npm run package:mac`：通过。V0.2 ZIP 解压到含中文和空格的路径后，使用**包内** Node 执行 `scripts/smoke-package.mjs`：通过，覆盖 SQLite 写入、备份下载、停止重启保留及前端路由。
- 从 V0.2 ZIP 解压包在本机终端实际执行 `启动.command` 与 `停止.command`：通过，隔离数据目录首次建库成功；两个脚本均保留可执行权限。此检查不等于从网络下载后在 macOS 上首次双击的验收。
- 在 `release/` 执行 `shasum -a 256 -c SHA256SUMS.txt`：V0.1 与 V0.2 两个本地 ZIP 均通过。
