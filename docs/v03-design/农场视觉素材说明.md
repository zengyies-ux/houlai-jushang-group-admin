# V0.3 农场视觉素材说明

## 来源与使用

以下四项为 2026-09-26 使用 OpenAI 内建 `image_gen` 生成的独立位图素材。输入图 `晨光农场日志-已选视觉基准.png` 仅用于像素密度、清晨光线和田园配色的风格参考；没有把整张效果图打包成页面背景，也没有从游戏安装文件或外部素材库提取图片。文字、日期、按钮和数据仍应由应用界面渲染。

本项目可将这些生成素材随本地应用构建与发布。它们不含另行引入的第三方素材许可证；生成内容的权利与使用仍以适用的 OpenAI 服务条款为准。所有装饰图均不承担功能图标或操作入口职责。

**总压缩大小：309,830 B（约 303 KiB）。** 图片随 Vite `public` 本地交付，不依赖在线资源。透明图需加 `alt=""` 或 `aria-hidden="true"` 并设置 `pointer-events: none`；文字不应使用像素化渲染。横幅适合 `background-size: cover; background-position: center 54%`，窄屏按边缘裁切；木纹条适合 `background-repeat: repeat-x; background-size: auto 100%`。侧栏图显示宽度建议约 200px，木牌上的真实文案由 DOM 单独排版。

## 生成与导出

每项均分别调用一次内建 `image_gen`。工具输出后用 `view_image` 实际检查主体、文字缺失与透明边缘，再用 macOS `sips` 做交付所需裁切/缩放，以 Pillow 仅编码为 WebP 或优化 PNG。没有使用效果图截图裁取资产。横幅输出本身为 2172×724，交付时保留主体所在的 2172×290 窄幅；不同屏宽仍由 CSS 裁切，不能拉伸变形。木纹条为图像纹理；左右边缘没有通过像素级无缝算法验证，实际接入时须检查重复接缝。
