# 后来居上组管理后台 V0.3.2 使用说明

本文件随 Mac arm64 成品包附带，无需打开源码仓库。V0.3.2 只交付 Mac arm64 运行包；正式服务应在办公 Mac 上运行，Windows 电脑通过可信局域网中的浏览器访问，不需下载 Windows 安装包。开发 Mac 使用隔离测试数据。

## 启动与停止

当前 Mac 成品仅适用于 Apple 芯片（`arm64`）；Intel Mac（`x86_64`）不能使用，需要另行构建和验证。在正式 Release 下载文件名以 `macos-arm64.zip` 结尾的**成品附件**及 `SHA256SUMS.txt`，核对后解压。GitHub 自动提供的 Source code ZIP 不是可双击运行的成品。私有仓库要在办公 Mac 自己的浏览器登录并取得下载权限，不要复制开发 Mac 的登录凭据。

启动脚本在解压后的顶层文件夹：双击 `启动.command`，浏览器应打开 `http://127.0.0.1:4173`；若未自动打开，手动输入此地址。打开「设置 → 技术信息与数据位置」，确认程序版本、架构和实际数据目录。停止时双击**同版本**文件夹的 `停止.command`。关闭浏览器不会停止服务；重复启动会提示已有实例。现有脚本在前台终端运行，关闭终端或系统重启后应重新启动。本版没有自动开机运行。Windows x64 独立运行包的构建与验证推迟到后续版本。

macOS 包未签名或公证。首次打开若被系统拦截，请在系统提供的“隐私与安全性”界面核对来源并选择打开；不要关闭系统保护。实际首次打开体验仍需在下载后的办公 Mac 验收。

首次无数据时会创建空工作台，不导入演示成员或任务。已有办公数据时，替换程序包不能清空或覆盖数据目录。默认只允许本机访问。核心功能无需连接 GitHub；联网只用于下载或更新。工作台时区默认为 `Asia/Shanghai`，截止日、本周和三天提醒按该时区计算。

## 日常使用

先在团队页创建小组、成员并指定组长。未分组成员可在团队页右侧直接选择小组，也可打开成员详情编辑组别；换组会保留组别和任务历史。没有上传头像时默认显示姓名的第一个字。点击成员详情里的头像文件选择框可上传或移除图片，支持 PNG、JPEG、WebP，最多 2 MB。

任务页创建任务时只需填写名称、负责人和截止日；项目名称可直接选填，小组、协作者、优先级等在“更多信息”。中途有人加入、退出或更换负责人时，打开任务详情的「参与人员 → 调整人员」，确认预览后保存；每次变化记入时间线。今天与任务列表中可直接点“标记完成”，无需先登记提交或验收。完成提示保留短暂的“撤销”“安排下一项”入口；如果提示已消失，可在已完成任务详情中“重新打开”。点状态可在未开始、进行中、待确认、已完成之间选择允许的动作；点截止日期可快速改成今天、明天、下周一或自选日期。“更多操作”可记一句当前进展或标记/解除可能延期，原因可选。所有操作保留事件历史并由服务端校验版本；保存冲突时请读取最新任务后再决定是否重试。

首页左侧「今天需要留意」收录未完成、未删除的逾期、今天截止、人工标记可能延期或待确认任务；右侧「未来三天交付」收录明天、后天、大后天截止的未完成任务。未来区显示的是“某项目有任务即将截止”，任务截止日不是整个项目的交付日。无项目名称的任务列在「未归项目」。同一任务可进入两区，但页面总“需留意”只计一次。两区的“查看全部”分别进入准确筛选，任务页还可按状态、小组、成员和项目取交集。完成、撤销完成、删除、改期或风险标记变化后会刷新提醒。提醒按工作台业务时区的自然日，而非距离当前 72 小时计算；跨日、休眠唤醒或重新聚焦后会更新。关闭网页时不会主动发送系统通知、邮件或推送；“临近截止”也不代表系统预测延期。原 `/reviews` 地址进入任务页的“待确认”筛选。成员暂停或离组后不能接新任务，已有交付和历史不会因此消失。

“日历”页可切换“按周”和“按月”；任务按截止日同时出现在两种视图，点击任务可查看详情，点击某日的“安排任务”会预填该日期。设置页可上传 PNG、JPEG 或 WebP 背景图（最多 6 MB），也可恢复默认外观。顶部按钮或“设置 → 农场外观”可切换浅色/深色模式；壁纸遮罩强度可调，方便在明亮或深色图片上阅读文字。显示模式和遮罩强度只保存在当前浏览器，背景和头像保存在主机数据库并随备份保存。

## 办公 Mac 主机与 Windows 浏览器

在**办公 Mac 本机**打开「设置 → 局域网访问」，输入至少 8 位访问口令，勾选允许访问，保存并停止、重启服务。设置页会列出办公 Mac 的可用地址，例如 `http://192.168.1.10:4173`。Windows 电脑接入同一可信私有网络，在浏览器输入**办公 Mac 的地址**并输入口令；Windows 自己的 `http://127.0.0.1:4173` 不会连接到办公 Mac。办公 Mac 必须保持开机、联网且不休眠。防火墙询问时按系统提示仅允许可信私有网络访问本应用；可在路由器为办公 Mac 保留固定局域网地址。真实办公 Mac 和 Windows 目标设备的连接仍需在那里验收。

局域网连接使用 HTTP，口令与业务数据传输没有加密，只适合可信私有网络；不要把端口转发到公网或使用不可信 Wi-Fi。口令、访问开关和恢复只能在办公 Mac 本机修改。开发 Mac 独立启动成品时，会使用另一份本机数据，**不会自动同步办公 Mac 的正式数据**。

## 数据、备份和迁移

V0.3.2 **继续使用原数据目录名称**，升级时不要手动改名。办公 Mac 默认正式数据目录为：

- macOS：`~/Library/Application Support/AIShortDramaWorkbench/data/`

Windows 浏览器访问办公 Mac 时，正式数据仍在办公 Mac；Windows 不需要创建本应用的数据目录。

数据库是其中的 `workbench.db`，备份在 `backups/`；头像、背景和任务历史也在数据库中。程序目录、Git 仓库与 iCloud 同步文件夹应和正式数据目录分开。更换程序包不会自动覆盖数据库。不要在服务运行时只复制 `.db` 而忽略 WAL；请使用页面提供的一致性备份，或先停止服务再完整复制数据目录。若使用自定义 `DATA_DIR`，启动、停止、备份和更新须统一使用实际目录，并记录下来。GitHub 不保存正式任务数据。

在办公 Mac 本机「设置 → 备份与恢复」点击“立即备份”，确认列表出现新快照，再点“下载”另存一份；建议保留受控的外部备份副本。服务运行时每日按需产生一次自动备份，默认仅保留最近 7 份日备份。恢复只能在办公 Mac 本机从设置页选择**该主机备份目录中已有的兼容备份**。恢复会先备份当前数据库、清除旧会话并要求所有页面刷新；操作前让其他设备停止编辑。恢复旧备份会失去备份之后的修改，先保存当前状态并确认时间点。

换主机时，先停止旧主机编辑并下载一致性备份；将备份文件放进办公 Mac 数据目录的 `backups/`，再在办公 Mac 本机设置页选择恢复，核对小组、成员、任务、历史、头像与背景。两台主机分别编辑产生的数据不能自动合并；已有办公数据不能被开发机数据库直接覆盖。旧程序发现更高版本数据库会拒绝启动；若后续版本升级数据库结构，回退程序前须检查兼容性，不能强行打开新库。

## 更新程序

本版没有自动下载或安装更新。更新正式稳定版的顺序是：在办公 Mac「设置 → 技术信息与数据位置」确认当前版本与**实际**数据目录 → 下载新成品并核对 SHA-256 → 在新目录备好程序 → 暂停所有设备编辑，在旧版点“立即备份”并下载快照 → 停止旧服务 → 切换程序入口并启动新版 → 核对版本、小组、成员、任务、事件、头像、背景、访问口令和 Windows 连接。备份与停止之间不允许其他页面继续写入；更新会短暂停用。仅替换程序，保留办公 Mac 正式数据。旧程序和更新前备份都应保留。回退前先核对数据库结构兼容；若必须恢复旧备份，先保存当前状态，并说明这会失去备份后的修改。

## 校验与限制

`SHA256SUMS.txt` 用于核对 Mac ZIP 完整性。Mac 终端输入 `shasum -a 256`，再把 ZIP 从 Finder 拖入终端并回车；输出应与清单中该文件对应的值完全一致。Mac 若首次打开被系统拦截，先核对来源和校验值，再在系统「隐私与安全性」中按提示允许，不要关闭系统保护。

- 本机网页打不开：确认启动终端仍在运行，试 `http://127.0.0.1:4173`，检查终端是否报告 4173 端口占用；不要为解决端口问题删除数据目录。
- Windows 连不上：在办公 Mac 确认服务、口令和局域网开关，保存后重启服务；核对设置页地址、同一局域网及防火墙。不要用 Windows 的 `127.0.0.1`。
- 更新后数据似乎消失：先核对「技术信息与数据位置」里的实际目录和当前 macOS 用户，不要在疑似错误的空库中继续录入，也不要直接覆盖办公库。
- 停止或重启异常：使用同一数据目录对应的 `停止.command`，避免新旧服务同时写正式库；将终端报错和当前版本交给维护者排查。
