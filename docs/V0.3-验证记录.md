- 检查 `apps/web/public/assets/farm/`：4 个本地素材合计 309,830 字节。尺寸、来源和用途记录在素材说明中。
- Playwright 隔离库：1280×800 首页首屏、900×800 窄屏及 1440×900/1920×1080 宽度检查；首页/团队/任务/周月日历/创建/详情/深色截图；完成、撤销、改期、记进展、标风险、项目 1/2 汇总、抽屉日期弹层与 Esc 焦点返回实际点测通过。
