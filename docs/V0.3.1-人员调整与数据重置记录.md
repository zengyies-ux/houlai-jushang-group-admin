# V0.3.1 人员调整与数据重置记录

更新日期：2026-09-26。

## 任务参与人员变动

- 任务详情增加“参与人员 → 调整人员”。可以在任务进行中新增、移除协作者，更换负责人；更换负责人时可明确勾选原负责人是否继续作为协作者。新负责人不会同时留在协作者列表。
- 保存前展示负责人变化、加入和退出的成员。保存使用任务版本校验和数据库事务；冲突返回 409，停用或离组成员不能作为新参与者。当前任务列表、成员当前任务和统计使用保存后的人员关系。
- 每次调整使用既有 `participants_changed` 事件记录操作时刻及调整前后人员快照；任务详情时间线显示人名变化。成员详情的任务历史仍可查到已退出的旧任务。未增加数据库迁移，也未增加自动工时、贡献归属或追溯改写历史的规则。
