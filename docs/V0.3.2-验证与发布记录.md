## 目标设备尚待验收

- **办公 Mac 尚未访问或安装。**首次下载、Finder 双击时的系统拦截、办公 Mac 芯片型号、局域网口令/地址、防火墙、停止重启后正式数据保留和备份下载，需要在那里按[办公 Mac 部署与更新](办公Mac部署与更新.md)实测。当前 Mac arm64 成品不适用于 Intel Mac。
- Windows 日常通过办公 Mac 的浏览器访问，不需要 Windows 独立运行包。真实 Windows 浏览器到办公 Mac 的局域网读写、休眠唤醒、断线恢复、目标设备离线运行与跨平台恢复仍需现场验收。CI runner 的构建与冒烟不能代替目标设备检查。
- GitHub 私有仓库存源码与正式运行 ZIP，不存业务数据库。办公 Mac 的真实数据应继续留在其本机数据目录；本轮只使用独立测试数据，没有执行历史“清空测试数据”操作。
